🎬 11-Step End-to-End Execution Pipeline

Live visual output from Satellite Input to Crew Decision

1. Satellite Input

Raw Synthetic Aperture Radar (SAR) input image from Sentinel-1 satellite.

2. Preprocessing

Lee Filter noise reduction, radiometric calibration, and contrast enhancement applied to raw SAR image.

3. Segmentation

Deep U-Net binary mask separating open sea water from sea-ice floes and icebergs.

4. Iceberg Detection

YOLO / ResUNet object detection bounding boxes with confidence scores.

Detected Icebergs: 2
5. Tracking (Simulated)

Kalman Filter + DeepSORT multi-target tracking assigning persistent IDs.

🧊 Iceberg 1 — Track ID: TRK-101
🧊 Iceberg 2 — Track ID: TRK-102
6. Trajectory (Simulated)

Physics-informed LSTM model predicting 24h / 48h / 72h iceberg movement paths.

7. Drift Forecast (Simulated)

Ocean current & wind force forecasting drift direction and speed vectors.

🧭 Iceberg 1 — Forecast drift: 1.04 km/h towards North-East
🧭 Iceberg 2 — Forecast drift: 1.13 km/h towards North-West
8. Hazard Fusion

Gradient Boosted Tree (GBT) computing concentric danger zones around icebergs.

9. Safety-First Route Optimization

A* + NSGA-II Pareto optimizer computing optimal safe route bypassing hazard zones.
